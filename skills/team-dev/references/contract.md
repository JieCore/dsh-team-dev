# 交付契约：L0 / L1 / L2

> 本文件是 team-dev / team-boot 的**不可覆盖底线**。项目规则、用户规则、任务卡只能在其上追加，不能替换或放宽 L0。读完这一页，再读项目规则。

## 1. 三层

| 层 | 定义 | 谁写 | 冲突 |
|---|---|---|---|
| **L0 不可覆盖** | 安全底线、质量门、交付面判定、最终声明 | 本文件 | L0 优先；项目只能追加更严要求 |
| **L1 项目追加** | 命令、目录、命名、接口风格、项目 §A 收尾、KB 沉淀 | 项目 AGENTS.md / CLAUDE.md / `.dsh/team-guidelines.md` 及其指针文件 | 可覆盖内置的 L1 默认，不可覆盖 L0 |
| **L2 任务 DoD** | 写作用域、验收命令、交付面、依赖 | Lead 的任务卡 | 与 L0 冲突时停下报告 |

**一句话：L1 决定“这个项目怎么做完”，L0 决定“做完之后怎么交付”。**

## 2. 完成 ≠ 交付

- 项目级 §A 可以定义“完成”（例如 5 条 KB 沉淀），但它**不能定义“交付”**。
- 收尾顺序固定：
  1. 项目级 §A 收尾（L1）；
  2. G1–G3 质量门；
  3. **L0 交付判定**：列出 artifact、决定 `present` 或声明无独立交付；
  4. 最终回复的交付声明。
- `team-out/*` 是证据/工作记录，不是 artifact。把 `team-out` 报告当交付面，是当前最常见的错误。
- 没有 artifact 时，必须明说「本次无独立交付文件」，不能静默跳过。

## 3. 交付面路由（L0）

| 本次主产物 | 主展示面 | present |
|---|---|---|
| 纯代码 / 配置 / 重构 | 改动卡片 + 正文 | 否 |
| 代码 + 正式报告（验收/交接/用户要读） | 改动卡片 + 交付卡片（只放报告） | 是，1 个报告 |
| 文档 / 报告 / 表格 / 幻灯片 / 图片 / 演示 / 导出 | 交付卡片 | 是，1–3 个 |
| 内部 evidence / review / verification / 任务板 | 正文链接 / 团队看板 | 否 |
| 探索 / 问答 / 临时文件 | 正文 | 否 |

不确定时：如果「最终回复 + 改动卡片」已经能说明白，就不 `present`；否则只 `present` 用户会打开/拿走的那 1–3 个文件。**无论选哪边，最终回复都要写交付声明。**

## 4. `present` 规则

- 只有 **Lead 在收尾轮**调用；成员不调用，成员把 artifact 路径写进回报/任务卡。
- `present` 的文件必须真实存在、在会话工作区内；一次 1–3 个，最多 8 个。
- 只放用户要打开/拿走的东西；不放源码 diff、不放 `team-out` 证据、不凑数。
- `present` 是卡片入口，不是完成徽章：任务是否完成看任务板/质量门，不看有没有卡片。
- `present` 不可用或失败时：正文写「交付物：`<path>`（未生成卡片）」并说明原因，不能假装已交付。
- 没有 artifact：不要调用 `present`，写「本次无独立交付文件」。

## 5. 项目规则发现（L1）

- 按 `references/project-profile.md` 的顺序发现规则；项目根 `AGENTS.md` 缺失不等于没有规则，`.dsh/` 下可能还有团队级文件和指针。
- 项目 §A 的收尾项写进 `team-out/00-onboarding.md` 的项目规则段；收尾时在 `team-out/delivery-report.md` 逐条勾。不要用 L0 替代项目 §A。
- 项目规则可以追加更严要求，**不得**：跳过测试、放宽安全、把 `team-out` 当 artifact、要求“不要 present/不要声明交付面”。
- 发现项目规则要求放宽 L0：停下报告用户/Lead，不要自行执行。

## 6. 冲突与升级

- L0 vs 项目：L0 胜；记录冲突点并报告。
- 项目 §A vs 任务卡：Lead 裁决；成员停下报告，不自行改需求。
- 不确定：按 L0 保守执行，并在最终回复标注「待确认」。
- 任何冲突都不得静默绕过。

## 7. 收尾验收（缺一不可）

- [ ] 项目 §A 收尾项已逐条完成（L1）
- [ ] G1–G3 通过，证据是命令输出或 `文件:行号`
- [ ] L0 交付判定已做：artifact 清单 + `present` 或「无独立交付文件」
- [ ] `team-out/delivery-report.md` 含「交付面」段
- [ ] 最终回复含交付声明
