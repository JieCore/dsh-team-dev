# .dsh/kb — 本工作区的共享记忆

目的：跨会话、跨团队记住**决策和坑**，让新会话不用重新摸一遍。
这里**不是**知识全貌，也不是文档库——只存"下次会改变做法"的内容。

## 目录

```
index.md            索引：每页一行，检索第一站
decisions/          决策记录（为什么这么定、否决了什么）
pitfalls.md         踩坑：现象 → 原因 → 规避（一行一条）
sources/            （可选）外部材料的摘要
```

## 用法

- **检索**：`grep "<关键词>" .dsh/kb/`（无需向量库）
- **读取**：`read` 命中的文件；对话里也可 `@路径` 直接引用
- **写入**：只在收尾时写，见 `.dsh/team-guidelines.md §A`

## 一条决策的格式

```markdown
---
title: 一句话标题
date: YYYY-MM-DD
status: accepted | superseded | proposed
sources: [文件:行号, 命令输出, 会话可检索词]
---

## 背景
## 决策
## 备选与为什么没选
## 后果（含风险与缓解）
## 何时重新评估
```

## 规则

- 一条一页，≤ 80 行；超了就拆
- 每条结论可核对：带 `文件:行号` 或命令输出；未验证标 `[待确认]`
- 不写"应该可以"
- 过时了标 `status: superseded` 并链到新页，**不要删除**
- 写完同步 `index.md` —— 不同步等于没写

## 成本（为什么这样设计）

- 根 `AGENTS.md` 每次会话都会加载（已压到 ≤2KB），所以规则只写指针，细节放这里
- 本目录 **0 固定成本**：不被 grep/read 就不进上下文
- 别把大段材料贴进来；材料放 `sources/`，正文只留结论与出处
